# 0.6.3.1 更新说明（候选草案，尚未发布）

让电脑 Codex 会话更容易接续，并减少不用远程模式时的界面干扰。

- 关闭远程模式时，侧边栏隐藏「电脑」入口；开启后再显示。
- 电脑会话列表增加新建入口，支持按会话标题、工作目录搜索。
- 修正远程新建会话的 sessionId 识别，并防止重复点击创建多份会话。
- 修正关闭远程模式后，迟到的配置读取重新显示电脑入口的问题。
- 未配对电脑时提供直接连接入口，返回设置后重新读取会话列表。
